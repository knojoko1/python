# Python Learning & Practice Repository

Welcome to my Python learning and practice repository (`knojoko1/python`)! This repository serves as a personal playground for exploring core Python concepts, writing scripts, solving practice problems, and expanding my software development skills.

---

## 📂 Repository Structure

The repository is organized into logical directories to keep code clean and modular:

*   **`basics/`**: Fundamental concepts (variables, data types, operators, and control flow).
*   **`functions/`**: Reusable code blocks, lambda functions, and scope handling.
*   **`oop/`**: Object-Oriented Programming (classes, objects, inheritance, and encapsulation).
*   **`data_structures/`**: Practice with lists, dictionaries, tuples, sets, and algorithms.
*   **`scripts/`**: Automation scripts and practical utilities.
